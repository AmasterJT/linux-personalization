# Icon themes

`Win11-Hypervisors` is a small overlay for the Win11 icon theme. It inherits
the complete theme from `Win11` and replaces only the application icons for
VirtualBox and VMware with the original vendor icons installed in `hicolor`.

The base theme is intentionally not vendored because it contains thousands of
files. Its upstream source is:

https://github.com/yeyushengfan258/Win11-icon-theme
